4. CHEAT SHEET: QUESTIONS YOUR TUTOR MIGHT ASK & YOUR ANSWERS
================================================================================

Q1: What database are you using?
A1: "MySQL Server 8.0, connected through the official MySQL Connector/J JDBC
    driver (mysql-connector-j-8.3.0.jar)."

Q2: What is your database schema?
A2: "I designed 3 relational tables:
     - medicines: stores batch ID, name, quantity, dates, supplier, price.
     - transactions: stores invoice ID, customer name, date, total amount.
     - transaction_items: stores sold medicines and quantities linked to
       transactions by Foreign Key."

Q3: How do you handle transactional safety during checkout?
A3: "During billing checkout, I use JDBC transactions: setAutoCommit(false),
     commit(), and rollback(). If writing line items or decrementing stock
     fails, the entire transaction rolls back to prevent data corruption."

Q4: Can a user sell an expired medicine?
A4: "No, the system compares LocalDate.now() against the batch's expiryDate.
     If the medicine has expired, the system blocks adding it to the bill."

Q5: Where is the database code located?
A5: "All database connection logic, SQL CRUD queries, and GUI presentation are
     consolidated into project.java for clean compilation and portability."
